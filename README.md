# Real Estate CRM

Production-grade multi-tenant real-estate CRM platform for web and mobile.

## Architecture

- Web: Next.js + TypeScript
- Mobile: Expo / React Native
- Backend: Supabase
- Database: PostgreSQL + Row Level Security
- Shared domain/types between web and mobile
- Native mobile calling/autodialer integration designed as a platform service

## Status

Foundation setup in progress.
